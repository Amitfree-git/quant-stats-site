# 量化统计学交互学习网站（离线版）

这是一个完全在本机运行的静态学习网站，基于《量化统计学基础》30 课课程包生成。

## 最快打开方式

直接双击：

```text
index.html
```

也可以双击：

```text
直接打开网站.command
```

网站不依赖互联网，也不需要安装 Node.js、数据库或 Python 包。

## 本地服务器方式

某些浏览器对 `file://` 本地页面的存储或下载权限较严格。遇到这类情况时，双击：

```text
使用本地服务器打开.command
```

该脚本只在 `127.0.0.1` 启动一个临时服务器，不向局域网或互联网开放。关闭终端窗口后服务器停止。

## 网站内容

- 30 课完整课程正文；
- 17 个交互统计实验；
- 6 个综合实战项目；
- 学习指南、公式速查、统计审计清单和研究模板；
- 全文搜索；

- 本地 CSV 收益率分析器。

1. 收益率、复利与波动拖累

3. 中心极限定理
4. 相关性与组合风险
5. 厚尾、VaR 与 Expected Shortfall
6. 置信区间、t 检验与统计功效
7. 线性回归、异方差与稳健标准误

9. AR(1)、ACF 与有效样本量
10. IID Bootstrap 与 Block Bootstrap
11. 多重检验、Bonferroni 与 FDR
12. IC、Rank IC、ICIR 与因子分层
13. IC Decay、换手率与交易成本
14. Fama–MacBeth 两步回归
15. 策略搜索与回测过拟合
16. 时间序列验证、Purging 与 Embargo
17. 本地 CSV 收益率分析器

## 数据隐私

所有模拟、图表和 CSV 读取均在浏览器本机完成。网站没有埋点、登录、远程接口或外部网络依赖。CSV 文件不会被上传。

## 学习记录存储

完成状态和笔记保存在浏览器 LocalStorage 中。清除浏览器网站数据可能会删除记录。建议定期在“学习进度”页面导出 JSON 备份。

## CSV 格式

CSV 第一行应为表头，至少有一列包含 5 个以上数值。支持逗号、分号或 Tab 分隔。百分数如 `1.25%` 会自动转换为 `0.0125`。

示例文件：

```text
示例数据/日收益率示例.csv
```

## 浏览器建议

优先使用当前版本的 Safari、Chrome、Edge 或 Firefox。直接打开模式已经过 Chromium `file://` 环境测试；服务器模式可作为兼容性备选。
