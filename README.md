# 量化统计学交互学习网站（离线版 · v1.1）

这是一个完全在本机运行的静态学习网站，内容包括 **1 个课前预备知识章、30 课量化统计学核心课程、21 个交互实验和 6 个综合项目**。

## 最快打开方式

直接双击：

```text

```

也可以双击：

```text
直接打开网站.command
```

网站不依赖互联网，也不需要安装 Node.js、数据库或 Python 包。

## 本地服务器方式

某些浏览器对 `file://` 本地页面的存储或下载权限较严格。遇到这类情况时，双击：

```text
使用本地服务器打开.command
```

该脚本只在 `127.0.0.1` 启动一个临时服务器，不向局域网或互联网开放。关闭终端窗口后服务器停止。

## 数据隐私

所有模拟、图表和 CSV 读取均在浏览器本机完成。网站没有埋点、登录、远程接口或外部网络依赖。CSV 文件不会被上传。

## 学习记录存储

完成状态和笔记保存在浏览器 LocalStorage 中。新版本沿用原来的存储键，旧版学习记录会继续保留；新增 P00 初始为未完成。清除浏览器网站数据可能会删除记录，建议定期导出 JSON 备份。

## CSV 格式

CSV 第一行应为表头，至少有一列包含 5 个以上数值。支持逗号、分号或 Tab 分隔。百分数如 `1.25%` 会自动转换为 `0.0125`。

示例文件：

```text
示例数据/日收益率示例.csv
```

## 浏览器建议

优先使用当前版本的 Safari、Chrome、Edge 或 Firefox。直接打开模式支持 `file://`；服务器模式可作为兼容性备选。
